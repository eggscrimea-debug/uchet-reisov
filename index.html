Новый рейс

В одном рейсе можно использовать разные схемы расчёта: ООО (НДС 22%), ИП (УСН 8%) и наличные. Расходы рейса распределяются между отправителями пропорционально их стоимости.
Для каждого отправителя отдельно указывается режим расчёта. Общая стоимость, получено, долг, налоги и чистый результат рейса считаются автоматически.

Расходы

Расходы вводятся один раз на весь рейс. Для расходов с НДС входной НДС учитывается только в части ООО-отправителей.
